## Bad Case
- BC-001：回答过长、重点分散；通过V2 Prompt约束回答长度及Top3改善。
- BC-002：数据不足时把潜在可达性问题直接标成高风险；V2.1加入证据约束后定向改善。
- BC-003：初步模拟偶尔被描述成“基本符合要求”，应避免超出证据结论。
- BC-004：TC-005把“散热格栅不能取消”弱化为“原则上应保留”；需加强硬约束遵循。
- BC-005：一次RAG尝试中Agent声称检索服务异常；后来RAG-001取得正确答案，但错误根因尚未核实。

## 离线工具测试与线上Agent测试的区别

- 它不能证明Dify模型自主调用工具成功。
