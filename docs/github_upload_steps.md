# GitHub网页上传操作

1. 打开 https://github.com/new
2. Repository name：`VLAB-Design-Agent-Evals`；Description：`AI Agent evaluation, RAG experiments and offline requirement-checking tools for vehicle design education.`
3. Visibility：Public。若准备使用本压缩包中已写好的README，请不要额外初始化一个README（避免重复）；不需要现在设置License。
4. 创建后点击`Add file`→`Upload files`；先在电脑上解压压缩包，把**压缩包中的文件和文件夹**拖入上传区域（不要只上传zip）。
5. 输入提交说明`Initial AI Agent evaluation portfolio and offline tools`，按界面按钮提交。
6. 返回仓库主页，确认README首页可见、`src`、`tests`、`data`、`docs`、`evidence`、`.github`目录存在。
7. 打开README检查显示是否正常。到个人主页`Your profile`→`Customize your pins`，将此公开仓库固定到主页。

如浏览器上传文件夹失败，可以逐个上传或改用GitHub Desktop；不要直接泄露真实API密钥、内部项目文件或参与者个人数据。
